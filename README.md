HSF Telemetry Monitor
Integración Hardware, Software y Firmware
Proyecto académico correspondiente al Segundo Corte.

Objetivo
Implementar una solución que integre hardware, firmware, sistema operativo y software mediante la simulación de un sistema de monitoreo de telemetría.

Tecnologías
Python 3
JSON
GitHub
Visual Studio Code
Estructura del proyecto
firmware: simulación del dispositivo
software: procesamiento de datos
data: almacenamiento de telemetría
logs: registro de eventos
docs: evidencias y documentación

Funcionalidades
Simulación de telemetría mediante firmware.
Lectura y procesamiento de datos JSON.
Consulta de recursos del sistema operativo.
Validación de datos recibidos.
Detección de anomalías.
Registro de eventos mediante logs.
Exportación de resultados a formato CSV.
